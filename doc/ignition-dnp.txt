system.dnp.demandPoll()                       *ignition-system.dnp.demandPoll*

  Issues a poll request for one or more classes.

  Syntax: >
    system.dnp.demandPoll(deviceName, classList)
<

  Parameters: ~
    {deviceName}  (String)  The name of the DNP3 device instance.
    {classList}   (List)    A List of classes (1, 2, 3) to issue polls.

  Returns: ~
    Nothing.

  Scope: Gateway

  Example: >
    system.dnp.demandPoll("DNP3", [1])
<

system.dnp.directOperateAnalog()     *ignition-system.dnp.directOperateAnalog*

  Performs a Direct Operate command on an analog point.

  Syntax: >
    system.dnp.directOperateAnalog(deviceName, variation, index, value)
<

  Parameters: ~
    {deviceName}  (String)   The name of the DNP3 device instance.
    {variation}   (Integer)  The Group 41 variation to use during the
                             operation.
    {index}       (Integer)  The index of the analog point.
    {value}       (Numeric)  The requested value.

  Returns: ~
    Nothing.

  Scope: Gateway

  Example: >
    system.dnp.directOperateAnalog("DNP3", 1, 0, 3.14)
<

system.dnp.directOperateBinary()     *ignition-system.dnp.directOperateBinary*

  Performs a Direct Operate command on a binary point.

  Syntax: >
    system.dnp.directOperateBinary(deviceName, index, tcc, opType, count, onTime, offTime)
<

  Parameters: ~
    {deviceName}  (String)   The name of the DNP3 device instance.
    {index}       (Integer)  The index of the binary point.
    {tcc}         (Integer)  Trip Close Code: 0=NUL, 1=CLOSE, 2=TRIP.
    {opType}      (Integer)  Operation Type: 0=NUL, 1=PULSE_ON, 2=PULSE_OFF,
                             3=LATCH_ON, 4=LATCH_OFF.
    {count}       (Integer)  The number of times the outstation shall execute
                             the operation.
    {onTime}      (Integer)  Duration (in milliseconds) the output drive
                             remains active.
    {offTime}     (Integer)  Duration (in milliseconds) the output drive
                             remains non-active.

  Returns: ~
    Nothing.

  Scope: Gateway

  Example: >
    system.dnp.directOperateBinary("DNP3", 3, 1, 3, 2, 5000, 5000)
<

system.dnp.freezeAtTimeAnalogs()     *ignition-system.dnp.freezeAtTimeAnalogs*

  Issues a Freeze at Time command targeting one or more analog points.

  Syntax: >
    system.dnp.freezeAtTimeAnalogs(deviceName, absoluteTime, intervalTime, indexes)
<

  Parameters: ~
    {deviceName}    (String)  The name of the DNP3 device instance.
    {absoluteTime}  (Long)    Absolute time (in milliseconds since epoch UTC)
                              when the initial action should occur.
    {intervalTime}  (Long)    Interval time (in milliseconds) between
                              periodic actions.
    {indexes}       (List)    The indices of the analog points to freeze.

  Returns: ~
    Nothing.

  Scope: Gateway

  Example: >
    from time import *
    
    fiveMikes = (60 * 1000 * 5) + int(time() * 1000)
    system.dnp.freezeAtTimeAnalogs("DNP3", fiveMikes, 0, [2, 4])
<
